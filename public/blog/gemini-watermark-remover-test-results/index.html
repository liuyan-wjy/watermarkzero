Gemini Watermark Removal: Sample Tests & Limits

By WatermarkZero · Updated October 1, 2026

On October 1, 2026, the local sample benchmark processed all 18 repository regression inputs and classified all 18 as passing its heuristic checks. This is a reproducible check of a fixed sample set, not a success rate for all Gemini images. The sample files do not record the generating model or version.

What this result establishes

  • The current engine applied removal to each of the 18 PNG and WebP sample inputs.
  • Each result passed the script’s residual-score and decision checks. These are automated indicators, not human ratings or comparisons with an original unwatermarked image.
  • The sample set includes normal, portrait, wide, and preview-size images. The largest side is 2928 pixels; it does not establish 4K model compatibility.
  • No claim is made here about iPhone/Android device testing, processing time, new Nano Banana model variants, JPEG quality levels, or screenshot success rates.

Reproduce the check

From a local checkout with its dependencies installed, run:

node scripts/sample-benchmark.js --output benchmark.json

The run reported pass=18 fail=0 total=18. The JSON includes each filename, whether removal was applied, the selected region, and classification. The checker requires removal to be applied and a sufficient decision tier; it flags processed residual scores at or above 0.22. That cutoff is an engine regression heuristic, not a visual-quality percentage.

See the benchmark source and local setup guide. Future code or sample changes can produce different results.

How to evaluate your own image

  • Use the original Gemini export and preserve an unedited copy.
  • Run the browser tool once, then compare the corner at 100% zoom.
  • Look for star outlines, pale patches, damaged text, and interrupted gradients or texture. A completed download alone is not a quality check.
  • If the output has a visible defect, retain the source and follow the troubleshooting guide.

Cases this benchmark does not settle

Cropped marks, recompressed JPG files, screenshots, and previously edited corners can behave differently from the fixed samples. The benchmark labels every sample as expected Gemini input; it does not measure false positives on a broad non-Gemini image collection.

WatermarkZero targets a visible corner overlay. These tests do not detect or remove SynthID, validate Content Credentials, or establish mathematically lossless restoration.
