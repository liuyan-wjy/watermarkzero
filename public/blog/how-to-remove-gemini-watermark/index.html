Use the uploader on the homepage and select a Gemini-generated image file. The MVP supports common image types such as JPG, PNG, and WebP. If the image does not match a supported Gemini visible watermark pattern, the tool may skip processing instead of forcing a risky edit.

Step 2: Let the browser detect the watermark

The Gemini watermark remover checks the likely watermark position and size locally in the browser. This is why the site can honestly say that the image stays on-device. The browser performs the detection and restoration work without sending the image to a remote processing queue.
