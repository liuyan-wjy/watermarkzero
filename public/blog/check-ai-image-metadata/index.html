Check AI Image Metadata: EXIF, C2PA & SynthID

By WatermarkZero · Published October 1, 2026

AI image metadata can include editing software, comments, location fields, and provenance records. Check the file itself before sharing: an image can have no visible logo but still contain metadata. WatermarkZero reports supported metadata categories in PNG and JPEG files; it does not identify which AI model made an image or verify C2PA signatures.

EXIF, XMP, C2PA and SynthID are different

InformationWhere it livesWhat a metadata check can tell you
EXIF and GPSMetadata attached to the image fileCamera, orientation, or location information may be present. GPS fields are not required in every image.
XMP, IPTC and text commentsEmbedded metadata blocksMay contain creator, editing, caption, or generation information. Their presence alone does not prove AI generation.
C2PA / Content CredentialsA provenance manifest, embedded or associated externallyCan record creation and editing history. Detecting a container is different from validating its signature and trust chain.
SynthIDAn imperceptible signal in image pixelsA normal metadata inspector cannot establish its presence or absence. Clearing metadata does not remove it.

Google explains that SynthID is embedded in pixels and can remain after metadata is lost. The C2PA FAQ explains that external credentials may also be rediscovered through fingerprints or other bindings.

Check a PNG or JPEG locally

  1. Keep the original file, then open the AI metadata remover. Choose PNG or JPEG files, up to 20 MB each. This tool does not accept WebP, HEIC, PDF, or video.
  2. Read the detected categories and removal summary. The page processes the file locally and prepares a separate cleaned copy; choosing it does not change the original.
  3. Look for categories relevant to your goal, such as EXIF/GPS for location privacy or comments/XMP for text fields. The report lists categories, not a complete display of every field and its value.
  4. Download the cleaned copy only if the changes match what you want. Compare it with the original before sharing.

For example, a report listing EXIF and GPS indicates that recognized EXIF metadata includes a GPS directory. It does not display coordinates. A report of “No removable metadata found” means this cleaner did not find a supported removable block, not that every possible hidden signal is absent.

How to inspect the actual field values

If you need to see exact timestamps, coordinates, or software names, use a local metadata inspector such as ExifTool. Once installed, these read-only commands list metadata from the original and cleaned files:

exiftool -a -G1 -s original.jpg
exiftool -a -G1 -s original.cleaned.jpg

Look at both the tag name and its group. File-system fields such as FileName and FileModifyDate describe the copy on your device and are not proof that private embedded fields remain. For C2PA validation, use a Content Credentials verifier that checks the manifest and its signatures. Do not infer authenticity from the filename or the mere presence of an XMP block.

What cleanup preserves

The metadata tool removes supported embedded metadata without re-encoding the image pixels. PNG image-data chunks and JPEG compressed image data are retained. Color-related information is retained, and JPEG orientation may be preserved in a minimal EXIF block so the photo still displays upright.

An EXIF category in a cleaned JPEG can therefore be expected if only orientation remains. Do not keep stripping or converting the file just to remove that label. Inspect its remaining fields if you need to confirm what was retained.

This differs from the visible watermark remover, which edits pixels around the corner mark and exports PNG. Choose the tool that matches the change you need.

Verify the copy you will actually share

  • Open the cleaned file and confirm its orientation, colors, dimensions, and visible content.
  • Inspect the cleaned file again, checking the categories or fields relevant to your privacy goal.
  • Keep the source if you need its provenance or editing history later. Removing embedded credentials can discard useful attribution records.
  • Check the final file after exporting from another editor. Later software can add new metadata; cleaning an earlier version says nothing about a later copy.

Does removing metadata make an image undetectable as AI?

No. Metadata cleanup does not remove SynthID, does not prove an image is human-made, and does not guarantee an AI detector result. Content Credentials may exist outside the downloaded file. Removing a recognized embedded container is not the same as erasing an image’s history.
