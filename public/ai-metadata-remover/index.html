1. Choose the original

Select PNG or JPEG files up to 20 MB each. WebP, HEIC, PDFs, and videos are not supported by this metadata tool. Keep an original copy if you need its capture details or provenance later.

2. Read the result

The card lists detected metadata categories and whether they were removed. It does not display a complete field-by-field report or certify who created the image. An EXIF badge alone does not mean GPS was present.

3. Download and check

Download the cleaned image, then select that downloaded copy to check it again. Removed categories should no longer appear. Retained JPEG orientation may still be reported so the photo displays correctly.

For example, a JPEG with GPS and camera EXIF can lose those fields while keeping its encoded picture and necessary orientation. A PNG without removable fields will report “No removable metadata found.” These are explanations of result states, not a claim that every image contains location data.

FAQ

What this cleaner can and cannot change

Claude, ChatGPT, and Gemini files: for PNG or JPEG files, supported container metadata can be removed when present. Cleaning is format-based, not model detection, so the same EXIF, XMP, IPTC, comment, and C2PA rules apply to files from other AI tools too.

Are files uploaded?

No. File reading, inspection, cleaning, and ZIP creation happen in your browser.

Does it reduce quality?

No image decoding or recompression is used. Only supported metadata segments are removed.

Does it remove SynthID?

No. SynthID and pixel-domain signals are outside this tool's scope. A clean metadata report cannot establish that an image was not AI-generated.

Why is the download almost the same size?

Metadata can be small compared with image data. Compare the reported categories, not file size alone, to check what changed.

Will the format or dimensions change?

A PNG stays PNG and a JPEG stays JPEG. The cleaner removes supported container segments rather than resizing or re-encoding the picture.

How do I save several files on a phone?

With at least two successful results, use Download ZIP. Open the ZIP in your phone's file manager to extract the images. Process smaller groups if the browser runs low on memory.
