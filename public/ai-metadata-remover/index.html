FAQ

What this cleaner can and cannot change

Claude, ChatGPT, and Gemini files: for PNG or JPEG files, supported container metadata can be removed when present. Cleaning is format-based, not model detection, so the same EXIF, XMP, IPTC, comment, and C2PA rules apply to files from other AI tools too.

Are files uploaded?

No. File reading, inspection, cleaning, and ZIP creation happen in your browser.

Does it reduce quality?

No image decoding or recompression is used. Only supported metadata segments are removed.

Does it remove SynthID?

No. SynthID and pixel-domain signals are outside this tool's scope.
