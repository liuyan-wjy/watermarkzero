Gemini settings guide

How to turn off the Gemini watermark

Updated October 1, 2026 · Settings checked against Google Help

To turn off the Gemini watermark, open Gemini, go to Settings → Media watermark, and switch it off. The change applies to media you create afterward. It does not update images you have already downloaded.

Turn off Media watermark for new images

  1. Open Gemini with the Google account you use to create images.
  2. Open Settings, then Media watermark.
  3. Switch off the visible watermark.
  4. Generate and download a new image. Check the downloaded file, rather than an older preview or an image saved before the change.

Google describes this control for visible watermarks on images, videos, and music created in Gemini Apps. For the current interface and availability, see Google's Media watermark instructions, checked October 1, 2026.

Why is the Gemini watermark toggle missing?

In India, South Korea, and Vietnam, Google says only Google AI Ultra subscribers can see this setting. That is a specific regional restriction; do not assume every account worldwide needs Ultra.

  • Check the signed-in account. A second browser profile may use a different account from the one where you generate images.
  • Compare your settings with Google's instructions for your device and region. Menu placement can differ between the app and browser.
  • If the option is unavailable, use an existing-image workflow for a downloaded image. WatermarkZero does not change your Gemini account settings.

If a new image still shows a mark, first confirm that it was generated after you changed the setting in the same account. Keep the original download so you can compare it with any edited copy.

Remove the visible mark from an existing download

A watermark in an older PNG, JPG, or WebP is already part of that file's pixels. Open the original export in the local image tool, compare the lower-right corner, and save the PNG if the result looks clean. The limit is 20 MB per image. Your image is processed in the browser.

Start with the original Gemini download. Screenshots, cropped edges, and compressed chat attachments can change the watermark pattern and leave a faint outline. If a file is skipped or the repaired area looks wrong, use the troubleshooting guide. Repeatedly processing a damaged copy is not a reliable fix.

For several images, use the batch queue and ZIP download. On a phone, follow the iPhone and Android save-and-download steps.

Does switching it off remove SynthID or Content Credentials?

No. Google states that the Media watermark setting does not affect SynthID or Content Credentials (C2PA). An image without a visible logo can still carry provenance signals.
