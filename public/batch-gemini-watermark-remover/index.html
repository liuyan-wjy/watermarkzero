Step 1

Choose the batch

Select several original Gemini exports at once. Mixed JPG, PNG, and WebP files are accepted, up to 20 MB per image. Start with a few files on a phone.

Step 2

Watch the queue

Keep the tab open while each file is checked locally. Read any error or skipped status: a completed queue does not mean a watermark was removed from every image.

Step 3

Review and download

Compare each result, then use Download All for a ZIP of completed PNG outputs. The ZIP can include skipped images with no confirmed removal; check them before publishing.

FAQ

Batch processing questions

How many files can I select?

There is a 20 MB limit per image. The usable batch size depends on image dimensions and device memory; there is no guaranteed unlimited batch. Split the set if your browser becomes slow or reloads.

Does it work offline?

Processing is local after the page and required assets have loaded. Keep the tab open until downloads finish. On a phone, extract the ZIP in Files or a file manager before saving individual PNGs to Photos.

Why was one file skipped?

The watermark may be cropped, resized, compressed, or unsupported. See troubleshooting.
