# WatermarkZero

WatermarkZero is a browser-based tool for removing the visible Gemini watermark from supported Gemini-generated images.

## What it does

- Removes the visible Gemini watermark locally in the browser
- Keeps image processing on-device instead of uploading files to a remote server
- Supports common formats such as JPG, PNG, and WebP
- Lets users preview and download the cleaned result

## Notes

- This tool is designed for the visible Gemini watermark only
- It does not claim support for every image
- It does not remove hidden watermarking systems such as SynthID
