# Chrome Web Store Listing Draft

## Name

Gemini Watermark Remover

## Short Description

Remove visible Gemini watermarks locally in your browser with no image uploads.

## Detailed Description

Gemini Watermark Remover is a local-first Chrome extension for supported
Gemini-generated images that contain the visible Gemini logo watermark.

Upload or drag a JPG, PNG, or WebP image into the extension popup, process it
on-device, preview the result, and download a PNG copy. The extension does not
upload your image to a remote server and does not load remote JavaScript.

What it does:

- Removes the visible Gemini watermark from supported Gemini image outputs.
- Runs the cleanup locally inside the extension popup.
- Supports JPG, PNG, and WebP input files.
- Exports the processed image as PNG.
- Links to the web version, privacy policy, and support page at WatermarkZero.

What it does not do:

- It does not remove hidden SynthID or other provenance signals.
- It is not a generic copyright-removal tool.
- It does not request access to Gemini, Google, or any website content.
- It does not add ads, tracking pixels, or remote scripts inside the extension.
